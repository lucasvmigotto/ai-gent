# Project recap, 2026-10-31

Status: Draft. Written before `dev` is promoted to `main`. Every figure comes from git or from files in this repository; where something was not checked it says so.

## What ai-gent is

Skills and plugins for Claude Code (the default) and, opt-in, opencode, Codex, Cursor, Antigravity, GitHub Copilot, Amp, Kiro and Windsurf, installed from this repository by symlink or generated entry files (`setup.sh`, `install.sh`). It is free software (GPL v3+) that covers the product pipeline from idea to released, documented product, and is frugal with tokens by design. `README.md` is the entry point; `CLAUDE.md` says how to change it.

## Plugins and skills

13 plugins and 49 skills at the time of writing (the docs site generator reports "13 plugins, 49 skills", version `2.22.0+c770a3f`). Plugins: `agents`, `backend`, `compact`, `db`, `devcontainer`, `devsecops`, `frontend`, `git`, `project`, `qa`, `repo`, `secrets`, `security`. A few carry Claude Code hooks (guards), runners (`dbrun`, `reporun`, `wt.py`, `token_report.py`) and, since specs 012-031, hooks modules ("mods").

## Promotion checklist

1. `bash scripts/check.sh` in full, including the installer tests and the update-check test.
2. Interactive probes on Claude Code 2.1.312: a cross-plugin `$.state.get` for an absent plugin (what it answers), a duplicate `/bands` command when several band plugins register it, the `session.append` origin shape (026), the 029 dashboard rendering, a live `gh run list` for 023, and whether `$.process.run` is visible to the guards.
3. Real-engine runs are needed only if `reporun.py` or `dbrun.py` changed. `git diff 2.22.0..dev --stat -- plugins/repo/scripts plugins/db/scripts` printed nothing at the time of writing, so `scripts/test-reporun-github.py` and `scripts/test-dbrun-engines.py` are not required.
4. `scripts/release.py --dry-run`, then promote; the release runs on push to `main`. Do not bump versions or tag by hand.
