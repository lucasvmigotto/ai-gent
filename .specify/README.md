# Spec Kit infrastructure

Bootstrapped 2026-11-17 using bundled specify-cli 1.0.14.dev0 templates and bash helpers. Portable templates, scripts and the first prospective constitution are committed. Host-generated .claude/skills, installed-integration manifests and local feature pointers are not part of this planning delivery. Install the matching integration locally if needed; do not overwrite existing skills without review.

Use explicit SPECIFY_FEATURE and SPECIFY_FEATURE_DIRECTORY for new specs; branch names do not select them. Set both variables to the same feature. The planning flow followed installed skill files for specify/clarify/plan/tasks/analyze rather than claiming a remote slash-command runner executed them. No extensions.yml is present, so no extension hooks apply. Core bootstrap is development infrastructure, not added to the runtime package allowlist.

Bundled upstream helper scripts/templates retain the GitHub Spec Kit MIT notice in `LICENSE.spec-kit`; source: https://github.com/github/spec-kit, installed distribution 1.0.14.dev0. ai-gent-authored constitution/specification text follows the repository license.
