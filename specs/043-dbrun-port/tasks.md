# Tasks: `dbrun` production port to Rust

Format: `- [ ] Tnnn [P] [USn] description. Files. Verify.` Each group is one worker; each task is one pull request into `dev` unless it says otherwise. Every task's output is reviewed by a different agent from its author (FR-033), and the evidence line names the reviewer and the findings (fixed or recorded). Nothing is built or checked off from this draft. A task marked "blocked: N" waits for open point N in `plan.md`. Engine tasks run the engines script for their engine only (`python3 scripts/test-dbrun-engines.py --runner <binary> --engine <name>`), one container at a time, removed by ID before the next; the owner approves image pulls.
