# Receipt semantic verification beyond JSON shape

Schema-valid is necessary, never sufficient. The receipt-valid-shape example is synthetic and deliberately does not supply a real evidence bundle; it is not a verifiable accepted task. IDs and digests are fixture values. receipt-invalid-domain.json has a valid JSON shape but must fail the future verifier because it claims complete acceptance with a missing-quality reviewer and inconsistent aggregate totals.

For accepted outcome require: matching repository/task fingerprint/attempt and generation; approved unchanged policy; every run in the registered coverage manifest closed; every required phase and parent resolved; no omitted failed attempts in the task accounting closure; source and evidence digests valid; exactly one authoritative contribution for overlapping observations; verified effective identities under strict policy; complete evidence; eligible fresh exact-artifact review; passing required checks. All phase totals include failed/cancelled runs. The accepting attempt receipt references prior attempt evidence via the registered coverage manifest, even though each run retains its actual attempt ID in the evidence bundle.

Compute exclusive input/output totals only from disjoint contributions. Cached/creation/reasoning totals are null if any relevant contribution lacks that breakdown; show known lower bounds separately in reports. Shared scopes are closed and linked, counted once globally, and not added to exclusive totals. A mixed-scope task receipt remains attribution=shared even when it also contains exclusive totals; it cannot advertise an exclusively measured full-task total.

For exempt outcome require a valid scoped owner exemption and report it separately; acceptance invariants cannot be waived by a worker-provided flag. Check replay protection, future schema rejection and evidence path restrictions before resolving references. Integration attestation is a separate artifact containing receipt digest, landing revision, covered artifact digest and verified merge/check evidence; it cannot rewrite the immutable original receipt.
