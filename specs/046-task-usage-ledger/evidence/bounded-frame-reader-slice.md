# Bounded v1 frame reader slice

This implements the first reader step from the proposed segmented-journal plan, without enabling storage v2 or changing any written bytes, counters or public response shapes. Registration and observation file loads preflight the same checked file handle using a fixed 64 KiB buffer, preserving whole-file size and final-newline error precedence, then rewind and decode through a bounded reader and reusable frame buffer. Both passes retain the 64 MiB limit. Decode-pass reads are capped at the limit plus one byte and explicit byte accounting rejects overflow, including growth after preflight.

The legacy line boundary remains 1 MiB **excluding** newline; writers still include newline in their bound. Payload checksums remain canonical, so noncanonical frame serialization remains accepted. Existing typed validation, registration/observation UUID checks, normalization and reduction are unchanged. Slice decoders used by recovery retain their upfront torn-tail check and do not acquire a new whole-log limit. No torn tail is silently trimmed.

The raw line buffer checks its length before extending and requests exact capacity. Preflight and decode use fixed I/O buffers. This removes whole-log raw byte vectors from these two load paths only. Decoded request vectors, registration state, contribution reduction, receipt verification and recovery allocations remain; **bounded total replay memory and the 100k/16-writer target are not qualified**. Preflight adds a source scan, so this change does not claim faster replay. Cooperative writers still share the existing lock; two passes do not provide a snapshot against arbitrary external modification.

Nine new tests cover literal UTF-8/chunk/newline boundaries, exact legacy line limits, generated infinite-line rejection with bounded buffer growth, empty/torn frames, size/tail preflight precedence, sanitized read/seek errors and interrupted reads, deterministic file growth after rewind, actual noncanonical registration frame acceptance at the legacy boundary, and both real journals' oversized/torn/malformed precedence.
