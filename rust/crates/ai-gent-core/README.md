# ai-gent-core

Shared library of the `ai-gent` command line (skills and plugins for AI coding agents):
the `--json` output envelope, exit codes, install paths and version information.

It is an implementation detail of the [`ai-gent`](https://crates.io/crates/ai-gent) binary and
has no stable API before 1.0.0. Project: <https://github.com/lucasvmigotto/ai-gent>.
