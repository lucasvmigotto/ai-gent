# ai-gent-compact

Token-lean source code reader of [ai-gent](https://github.com/lucasvmigotto/ai-gent): a compact
view of a source file (indentation and optional spaces removed, strings and comments kept,
self-verified) and an outline with the original line numbers. It ships as its own binary,
`ai-gent-compact`, with its own size budget, apart from the core `ai-gent` binary (decision D29).

This 0.1.0 release only reserves the name; the tool lands with a later version.
Project: <https://github.com/lucasvmigotto/ai-gent>.
