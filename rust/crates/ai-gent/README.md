# ai-gent

The command line of [ai-gent](https://github.com/lucasvmigotto/ai-gent): skills and plugins for
AI coding agents. Install it with the project's `install.sh`, which fetches a verified release
archive; this crate exists so the name and sources are public.

Docs: <https://docs.lucasvmigotto.me/ai-gent/>.
